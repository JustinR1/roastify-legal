# Roastify AI - Legal Documents

This directory contains the hosted legal documents for Roastify AI.

## 🌐 GitHub Pages Setup

These HTML files are hosted via GitHub Pages for App Store compliance.

### Setup Instructions:

1. **Enable GitHub Pages:**
   - Go to your GitHub repo: Settings → Pages
   - Source: Deploy from a branch
   - Branch: `main` (or `master`)
   - Folder: `/docs`
   - Click Save

2. **Your URLs will be:**
   ```
   Privacy Policy: https://JustinR1.github.io/ai-roast-me/privacy-policy.html
   Terms of Service: https://JustinR1.github.io/ai-roast-me/terms-of-service.html
   ```

3. **Use these URLs in:**
   - App Store Connect (Privacy Policy URL field)
   - Your app's settings/about page
   - Marketing materials

## 📄 Files

- `index.html` - Landing page with links to legal docs
- `privacy-policy.html` - Privacy Policy
- `terms-of-service.html` - Terms of Service
- `README.md` - This file

## ✏️ Updating Content

To update the legal documents:
1. Edit the HTML files in this directory
2. Commit and push to GitHub
3. Changes will be live within a few minutes

## 🔗 Custom Domain (Optional)

If you have a custom domain (e.g., `roastify.app`):
1. Add a `CNAME` file to this directory with your domain
2. Configure DNS records with your domain provider
3. Enable HTTPS in GitHub Pages settings

Then your URLs become:
```
https://roastify.app/privacy-policy.html
https://roastify.app/terms-of-service.html
```
